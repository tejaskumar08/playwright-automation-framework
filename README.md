# 🎭 Playwright Automation Framework

🚀 **Playwright Web and API Automation Framework**

---

## ✅ **Features Covered**

### 🌟 Test Cases:
- 🔒 **Login**
- 🔄 **Login using saved session info**
- ➕ **More to be added...**

### 🏗️ Framework Enhancements:
- 🧩 **Page Object Model (POM)** for better structure.
- 🛠️ **Playwright Assertions** for robust validations.
- 💾 **StorageState Functionality** to store and reuse login sessions.
- 🌐 **Dotenv Library** for managing environment variables.
- 🔐 **Encryption & Decryption** with SALT value in Node environment.
- 🔄 **API Mocking** with demo test cases.
- 🧪 **Custom Fixtures** for reusable test setups.
- 📜 **Logging Library** for detailed test logs.
- 🔄 **CI/CD Integration** with GitHub Actions and Jenkins.
- 🌐 **API Testing** using:
  - Existing POM page context.
  - APIRequest context.
- 📊 **API Monitoring** (test cases to be added).
- 🖥️ **Playwright MCP Server Support** with:
  - Necessary configurations.
  - Prompt file for manual test case generation.

## 📖 **How to Use**

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm ci
   ```
3. Run tests:
   ```bash
   npx playwright test
   ```
4. View reports in the `playwright-report` directory.
